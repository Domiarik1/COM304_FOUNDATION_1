## Personal Notes and research following this session

*Which class sessions and personal research refers to technology in this proposal. Link to examples.*

Computer Architecture: This was coined in the 1960s by the designers of the IBM system/360 to mean the structure of a computer that a machine language programmer must understand to write a correct program for a machine. Basically, Computer Architecture represents the programming model of the computer, including the instruction set and the definition of register file, memory, and so on. Over time, the concept of Computer Architecture has evolved to include both functional specification and the hardware implementation, At the system level, it defines the processor-level building blocks, such as processors and memories, and the interconnection among the building blocks. At the microprocessor level, computer architecture determines the processor's programming model and its detailed implementation. The implementation of a microprocessor is also know as microarchitecture. The task of a computer architect is to understand the state of the art technologies at each design level and the changing design tradeoffs for theit specific applications. The tradeoffs of cost, performance, and power consumption is fundamental to a computer system design. Different designs result from the selection of different points on the cost-performance-power continuum, and each application will require a different optimum design point. For high-performance server application, chip and system costs are less important than the performance. Computer speedup can be accomplished by constructing more capable processor units or by integrating many processors unit on a die. For cost-sensitive embedded applications, the goal is to minimize processor die size and system power consumption.
