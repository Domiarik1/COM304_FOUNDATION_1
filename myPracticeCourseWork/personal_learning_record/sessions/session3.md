Experiments with IO on Raspberry Pi: This resulted in a stronger understanding of how computers interact with the physical world. Through hands-on projects involving the GPIO pins, learnt how digital signals work and how software can directly control hardware components. Activities such as blinking LEDs, reading button stated, or connecting sensors help me undertood the fundamental electronics concepts like voltage, current, and resistance, while also teaching me how to wire circuits safely and correctly. As i experiment more i gained the experience writing Python code to manage inputs and outputs. This strengthens my prpgramming skills and shows me how code can respond to real-time events, such as turning on an LED when a button is pressed or collecting data from environmental sensors. These projects help develop logical thinking, troubleshooting abilities, and a deeper appreciation for how software and hardware must align for a system to function correctly. Working with IO is also helping me build my confidence in creating interactive and automated systems. beginning to understand how everyday technologies like alarms or temperature monitors are built from simple components combined with clear logic.
