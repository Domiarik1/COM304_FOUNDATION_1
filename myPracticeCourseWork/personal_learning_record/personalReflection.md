* What have you learnt that is new.
I have learnt computer Architecture, this describes how a computer's hardware components are organised and interact, It includes the CPU, memory, storage, input/output devices, and the system bus. These elements work together to process instructions, manage data flow, and ensure efficient performance, forming the foundation for all computer operations and software execution. Binary and Boolean, This is a base-2 number system using only 0s and 1s, representing how computers store and process data electronically. Boolean logic uses true/false values to create logical operations like AND, OR, and NOT. Together, binary and Boolean form the foundation of decision-making and data processing indigital systems. Experiments with IO on Raspberry Pi, this involve using the GPIO pins to control and read external components. Simple projects include blinking LEDs, reading button inputs, and connecting sensors. These activities help yopu understand digital signals, circuit basics, and how software interacts with hardware, building practical skills in electronics and programming. Computer Languages, This are system of rules and syntax that allows humans to communicate instructions to computers. They include low-level languages like assembly, which interact closely with hardware, and high-level languages like python or java, which are easier to read and write. These languages enable software development, qutomation, and problem-solving technology. Node-RED, This is a visual programming tool that lets users create automation flows by connecting nodes instead of writing code. It uses a browser-based editor where data moves between nodes to perform tasks. Common uses include loT projects, APIs, and home automation, making it beginner-friendly yet powerful for rapid development.
