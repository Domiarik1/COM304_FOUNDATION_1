Use this session to consolidate your knowledge and write up what you have done so far.

Git: Is a distributed version control system that allows developers to track cjanges in source code, collaborate efficiency, and maintain project history. It supports branching, merging, and rollback, giving teams flexibility when building software. GitHub, GitLab, and Bitbucket provide cloud-based platforms for sharing Git repositories.

Raspberry Pi: Is a compact, low-cost computer designed for education, experimentation, and embedded projects. It supports Linux-based operating system and is widely used for programming, robiotics, IoT systems, and learning computer hardware basics.

Computer Architecture: It describes how hardware components such as the CPU, memory, storage, and input/output systems interact. Key ideas include the fetch-decode-execute cycle, instruction sets, data paths, and performance concepts like pipelining and caching.

Binary and Boolean Logic: Brinary, consisting of 0s and 1s, is the foundation of the digital systems. Boolean logic uses AND, OR, NOT, and related operations to control how circuits behave. Together, they allow computers to process data and make logical decisions.

History of Computing: Computing evolved from early mechanical devices like the abacus and Babbage's Analytical Engine to electronic computers such as ENIAC. The development of transitors, integrated circuits, and microprocessors sparked the digital revolution.

Structure of a Modern Operating System: A modern OS has several key layers; the kernel, which manages hardware, memory and process management systems, device drivers, and user level components like file systems and interfaces. It ensures multitasking, security, and hardware abstraction.

Cloud Computing: Cloud computing resources servers, storage, databases, and applications over the internet. It provides scalable , on demand services through models such as IaaS, PaaS, and SaaS. Cloud platforms increase flexibilty, reduce cost, and support global accessibility.
